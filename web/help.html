LiveTalking 使用教程

按这个顺序操作：先建立 WebRTC 连接，再用文本或音频驱动数字人说话。页面右上角从 未连接 变成 已连接 后，才可以发送内容。

最快上手

1

打开主页

访问 http://127.0.0.1:5555/index.html。看到右上角 未连接 是正常状态。

2

点击“开始连接”

三个输入框可以先留空。连接成功后，右上角会显示 已连接 和一个 SID。

3

发送一段文字

在“文本驱动”里保留 Echo 复读，输入一句话，点击“发送”。数字人会用 TTS 播放这段话并同步口型。

4

需要停下时点击“打断”

长文本播放中可以用“打断”清空当前播报，再发送新的内容。

页面截图

连接区在左侧，文本/音频/录制/动作控制在右侧。实际页面会根据窗口宽度自动换行。

真实使用例子

客服欢迎语

选择 Echo 复读，输入：

您好，欢迎来到我们的直播间。请告诉我您想了解哪款产品。

课程讲解

输入一段分句清楚的讲稿，例如：

今天我们学习三个重点。第一，什么是实时数字人。第二，如何连接 WebRTC。第三，如何用文本驱动播报。

直播口播切换

正在播放时勾选“打断”，发送新文案：

现在进入限时优惠环节，请看屏幕右侧的商品链接。

常用控件

  • Avatar ID：留空时使用服务启动时的默认形象。
  • 参考音频：EdgeTTS 里可填写音色名，例如 zh-CN-YunxiaNeural。
  • Echo 复读：直接播报你输入的文本，适合本地测试。
  • Chat LLM：让后端调用大模型回复，需要配置 DASHSCOPE_API_KEY。
  • 上传音频：上传音频文件后用原音频驱动口型。

如果没有反应

仍然显示“未连接”

确认已经点击“开始连接”。如果弹出错误，先刷新页面再重试一次。

可以连接但不说话

先用 Echo 复读 测试，不要先用 Chat LLM。Chat 需要大模型 API Key。

想确认服务状态

打开 管理后台 查看当前配置和会话列表。

本地测试建议：先留空连接参数，连接成功后发送一句短文本。等这条链路稳定，再尝试自定义音色、上传音频、录制和 Chat LLM。
